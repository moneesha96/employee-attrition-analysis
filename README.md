# employee-attrition-analysis
SQL analysis of employee attrition data, exploring workforce trends, turnover patterns, and key factors associated with employee attrition.

Methods:
Analysed employee data to investigate the factors associated with staff attrition. Used SQL to clean, filter and analyse the data, applying techniques such as GROUP BY, aggregate functions, CASE statements and filtering. Created visualisations to compare attrition across factors such as job role, department, age, income and job satisfaction.

Key Findings:
The analysis identified employee groups with higher attrition rates and highlighted workplace and demographic factors associated with employees leaving the organisation. The findings helped identify areas where organisations could focus their employee retention strategies.
